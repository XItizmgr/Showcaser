## Abour Showcaser.


Showcaser is an image-showcasing website featuring 25 different
monochrome images. This website was built to practice and explore
Lenis and GSAP in JavaScript. Lenis is a lightweight JavaScript
library for smooth scrolling, while GSAP is a powerful animation
library with plugins such as ScrollTrigger. This website uses
ScrollTrigger with scrub to connect animations to the scroll position.
